## 1. Executive Summary
The "Physicalized Agent" is a low-cost, high-performance edge node designed to provide "Reasoned Governance" in healthcare environments. Unlike traditional AI cameras that rely on expensive, "black box" ML inference, this system uses **deterministic signal processing** (DSP) and **spatial geometry** to create a 3D logic map of an environment.

It serves as the physical interface for a cloud-based Agentic ERP, capable of autonomous "Safety Overrides" (local governance) while streaming logical telemetry to the cloud via WebTransport.

## 2. Hardware Architecture (The "Body")
**Core Constraint:** Ultra-low cost, high availability, off-the-shelf components.

### 2.1 Compute & Control
* **Primary MCU (The Brain):** **Waveshare ESP32-P4-WIFI6-M**
    * *Spec:* Dual-Core RISC-V @ 400MHz, **32MB PSRAM** (Critical for buffering).
    * *Role:* Sensor fusion, DSP vectorization, H.264 encoding, Local Governance Logic.
* **Comms Co-Processor (The Radio):** **ESP32-C6** (Onboard)
    * *Interface:* **SDIO 3.0** (High-speed 4-bit parallel bus).
    * *Role:* Wi-Fi 6 (802.11ax) PHY, QUIC/TLS offload.

### 2.2 Sensory Array
* **Visual (Hybrid Stereo):**
    * **Primary Eye:** **OV5647 (5MP) via MIPI-CSI**.
        * *Function:* High-Res "Diagnostic" Imaging, H.264 Hardware Encoding.
    * **Secondary Eye:** **OV2640 (2MP) via DVP**.
        * *Function:* Stereoscopic parallax context, low-power motion tracking.
* **Auditory (Binaural):**
    * **Sensors:** 2x **INMP441** (MEMS, I2S Interface).
    * **Configuration:** "Bottom-Port" mounting in custom acoustic horns.
    * *Function:* Spatial localization (Azimuth + Elevation) via ITD/ILD/Spectral cues.

### 2.3 Actuation
* **Mechanism:** 2-Axis Pan/Tilt Gimbal.
* **Drivers:** 2x High-Torque Metal Gear Servos (driven via ESP32-P4 MCPWM).

## 3. Logical Architecture (The "BIOS")
**Philosophy:** "Determinism over Probability." The edge device calculates **Vectors**, not "Guesses."

### 3.1 Signal Processing (DSP Layer)
* **Audio Pipeline:**
    * Raw I2S PCM $\rightarrow$ FFT (RISC-V DSP Extension) $\rightarrow$ Spectral Notch Analysis (Verticality) + Cross-Correlation (Horizontal Azimuth).
    * *Output:* Audio Vector $\vec{A} = \{ \theta_{az}, \phi_{el}, \text{intensity} \}$
* **Video Pipeline:**
    * MIPI/DVP Ingest $\rightarrow$ Hardware PPA (De-warping/Rectification) $\rightarrow$ Centroid Logic.
    * *Output:* Visual Vector $\vec{V} = \{ x, y, z_{\text{est}}, \text{mass} \}$

### 3.2 The Governance Engine (State Machine)
* **Fusion Logic:** Compares $\vec{A}$ and $\vec{V}$.
* **Rule Set (Example):**
    * *IF* Audio Source is Floor Level ($<20cm$) *AND* Audio Intensity > Threshold (Scream/Thud)
    * *THEN* Priority = CRITICAL. Override current task.
    * *ACTION:* Slew Servos to Audio Vector. Capture High-Res JPEG. Open "Heartbeat" Stream.

## 4. Communication Architecture (The "Nerve")
**Protocol:** **WebTransport over HTTP/3 (QUIC)**.
**Strategy:** "Connection Jealousy" (Stream Prioritization).

| Stream ID | Type | Content | Priority | Reliability |
| :--- | :--- | :--- | :--- | :--- |
| **Stream 0** | Bidirectional | **Heartbeat & Governance Control** | **Critical** | High (Retransmit) |
| **Stream 1** | Unidirectional | **XYZ Vector Map (JSON-LD)** | High | Low (Drop old frames) |
| **Stream 2** | Unidirectional | **Diagnostic Audio (AAC)** | Medium | High |
| **Stream 3** | Unidirectional | **High-Res Video (H.264/JPEG)** | Low | Medium (Burst) |

* **Cloud Endpoint:** Google Cloud Run (Serverless Agent). Scales to zero when "Heartbeat" is nominal.

## 5. Industrial Design (The "Form")
**Goal:** Bio-mimicry for performance, not aesthetics.

### 5.1 Acoustic Enclosure
* **Geometry:** Asymmetric **Logarithmic/Conical Horns** (~30mm diameter).
* **Feature:** Internal "Spectral Notch" ridge for vertical localization.
* **Shadowing:** 100% Infill "Shadow Block" between horns to maximize Interaural Level Difference (ILD).
* **Mounting:** Vibration-damped "Concha" adapter for INMP441 (Bottom-ported).

### 5.2 Sensor Head Layout
* **Base:** Standardized mount for Pan/Tilt servos.
* **Eyes:** Spaced at ~60mm (human baseline) for effective stereoscopic disparity.
* **Ears:** Mounted laterally, slightly recessed to create forward-bias directionality.
